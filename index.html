Overview

A Windows client.
A real WireGuard tunnel.

An open-source WireGuard GUI for Windows, with a native interface and a Rust VPN client core. Bring your own WireGuard configuration; waX VPN is a client, not a VPN server subscription.

waX VPN is being built around the official WireGuard for Windows kernel driver, with a Rust core and a Rust-rendered interface. The tunnel has passed live CI checks against the official WireGuard demo server: handshake, a ping through the tunnel, DNS setup and restore on a clean disconnect, and a GUI-driven connect. There is no kill switch yet: if the tunnel drops, traffic can use the normal connection. Every claim on this page is labeled: what is verified, and what is still on the roadmap.

Rust end to end

Core logic, tunnel control and interface code are all Rust. The desktop UI is egui, an immediate-mode GUI written entirely in Rust - no embedded browser engine, no JavaScript layer.

Real WireGuard tunnel

Tunnel code drives the official WireGuard for Windows kernel driver through the wireguard-nt Rust crate - a real system VPN design, not a browser trick or userspace packet relay. Live handshake, a through-tunnel ping, and a GUI-driven connect are all verified in CI.

Cloudflare WARP, built in

WARP client code is written to the wgcf-compatible protocol in Rust, strictly opt-in: nothing registers with Cloudflare until you ask it to. Live compatibility with the WARP service has not been tested yet.

FAQ

Straight answers.

Can I download waX VPN yet?
Yes - v0.1.41 for Windows is the current stable release. It is an unsigned build that requires administrator rights, so Windows publisher/SmartScreen warnings are expected. Its exact stable gate passed, including a GUI-driven Connect handshake, through-tunnel ping, DNS apply/restore, split-tunnel exclusions, adapter-loss recovery, close-to-tray and graceful quit, and a fresh-runner install, GUI launch and uninstall (a CI Windows runner, not a consumer-PC/SmartScreen test). There is no kill switch - if the tunnel drops, traffic can use the normal connection - and no IPv6 leak-protection claim. The UAC restart path, tray menu and live WARP are still unverified, and the interface is still being refined. Verify the SHA-256 in the Download section before running.
Is it a real VPN or a proxy?
waX is built to be a real system VPN: its tunnel code integrates the official WireGuard for Windows kernel driver, so all apps would route through the tunnel - not just one browser. A live handshake and clean disconnect against a WireGuard demo server have passed in CI, along with a GUI-driven connect and a through-tunnel ping; general real-machine traffic and crash safety are still pending.
What does WARP built in mean?
waX includes a Rust client written to the Cloudflare WARP API (the same protocol wgcf uses), so you could create and use WARP profiles without a separate tool. It is opt-in: no registration happens until you choose it in the app. Live interop with Cloudflare is untested, and WARP use is subject to Cloudflare's own terms.
Which platforms?
Windows first and only, for now. Focusing on one platform keeps the tunnel, installer and UI polished instead of spreading thin.
Is the source public?
Yes. Development happens in the open at github.com/vio137/wax-vpn.
