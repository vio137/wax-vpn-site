Overview

A real system VPN,
not a proxy in disguise.

waX VPN is built around the official WireGuard for Windows kernel driver, with a Rust core and a Rust-rendered interface. Every claim on this page is labeled: what exists today, and what is still on the roadmap.

Rust end to end

Core logic, tunnel control and interface code are all Rust. The desktop UI is egui, an immediate-mode GUI written entirely in Rust - no embedded browser engine, no JavaScript layer.

Real WireGuard tunnel

Built on the official WireGuard for Windows kernel driver through the wireguard-nt Rust crate. A true system VPN interface, not a browser trick or userspace packet relay.

Cloudflare WARP, built in

WARP support is implemented with a wgcf-compatible client written in Rust. It is strictly opt-in: nothing registers with Cloudflare until you ask it to, inside the app.

Architecture

Four crates, one tunnel.

The planned workspace layout. Each layer is a separate Rust crate with a single job. PLANNED

wax-app

Interface - egui native GUI

Animated immediate-mode desktop interface written entirely in Rust. No WebView, no browser engine bundled.

wax-core

Profiles and keys

WireGuard config parsing, key generation and profile storage.

wax-tunnel

Driver control - wireguard-nt

Creates and manages the kernel tunnel adapter through the official WireGuard for Windows driver.

wax-warp

WARP client - wgcf-compatible

Talks to the Cloudflare WARP API to register and manage WARP profiles. Runs only when you opt in.

FAQ

Straight answers.

Can I download waX VPN yet?
Not yet. The app is in active development and the first preview installer has not shipped. Releases will appear on the GitHub releases page when they exist and pass checks. This site will link them directly, with hashes.
Is it a real VPN or a proxy?
The plan is a real system VPN: waX uses the official WireGuard for Windows kernel driver, so all apps route through the tunnel - not just one browser.
What does WARP built in mean?
waX includes a Rust client for the Cloudflare WARP API (compatible with what wgcf does), so you can create and use WARP profiles without a separate tool. It is opt-in: no registration happens until you choose it in the app, and WARP use is subject to Cloudflare's own terms.
Which platforms?
Windows first and only, for now. Focusing on one platform keeps the tunnel, installer and UI polished instead of spreading thin.
Is the source public?
Yes. Development happens in the open at github.com/vio137/wax-vpn.
