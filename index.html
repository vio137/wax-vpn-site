Overview

Designed as a real system VPN,
not a proxy in disguise.

waX VPN is being built around the official WireGuard for Windows kernel driver, with a Rust core and a Rust-rendered interface. The driver integration is written and type-checked; live routing on Windows has not been runtime-tested yet. Every claim on this page is labeled: what exists today, and what is still on the roadmap.

Rust end to end

Core logic, tunnel control and interface code are all Rust. The desktop UI is egui, an immediate-mode GUI written entirely in Rust - no embedded browser engine, no JavaScript layer.

Real WireGuard tunnel

Tunnel code targets the official WireGuard for Windows kernel driver through the wireguard-nt Rust crate - a real system VPN design, not a browser trick or userspace packet relay. Runtime verification on Windows is pending.

Cloudflare WARP, built in

WARP client code is written to the wgcf-compatible protocol in Rust, strictly opt-in: nothing registers with Cloudflare until you ask it to. Live compatibility with the WARP service has not been tested yet.

Architecture

Four crates, one tunnel.

Interface - egui native GUI

Animated immediate-mode desktop interface written entirely in Rust. No WebView, no browser engine bundled.

wax-core

Profiles and keys

WireGuard config parsing, key generation and profile storage.

wax-tunnel

Driver control - wireguard-nt

Creates and manages the kernel tunnel adapter through the official WireGuard for Windows driver.

wax-warp

WARP client - wgcf-compatible

Talks to the Cloudflare WARP API to register and manage WARP profiles. Runs only when you opt in.

FAQ

Straight answers.

Can I download waX VPN yet?
Yes - the first preview installer for Windows is out: v0.1.0-preview.6. It is an unsigned development build that requires administrator rights. Install, tunnel, kill switch and GUI are not runtime-verified yet, so treat it as a preview and verify the SHA-256 shown on the release page before running.
Is it a real VPN or a proxy?
waX is built to be a real system VPN: its tunnel code integrates the official WireGuard for Windows kernel driver, so all apps would route through the tunnel - not just one browser. A live handshake and clean disconnect against a WireGuard demo server have passed in CI; full runtime verification (general traffic, kill switch, crash safety, GUI-driven connect) is still pending.
What does WARP built in mean?
waX includes a Rust client written to the Cloudflare WARP API (the same protocol wgcf uses), so you could create and use WARP profiles without a separate tool. It is opt-in: no registration happens until you choose it in the app. Live interop with Cloudflare is untested, and WARP use is subject to Cloudflare's own terms.
Which platforms?
Windows first and only, for now. Focusing on one platform keeps the tunnel, installer and UI polished instead of spreading thin.
Is the source public?
Yes. Development happens in the open at github.com/vio137/wax-vpn.
