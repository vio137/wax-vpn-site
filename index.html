What changed in v1.0.30?

Latest change: Windows Defender falsely flagged the v1.0.29 installer download on one PC. The published file was intact (SHA-256 matched), but the installer and both app binaries carried no Windows version metadata - a common antivirus ML false-positive trigger for unsigned NSIS installers. v1.0.30 embeds full version information into both executables and the installer. No functional, settings or networking change. The build remains unsigned, so SmartScreen and antivirus warnings may still appear. Tested on hosted Windows Server 2025, not a clean Windows 10/11 image. This is not proven to fix the startup crash on a user's PC. The Network page introduced in v0.1.43 includes public IP before/after, a live throughput graph, an HTTPS latency graph and a manual 10 MB speed test. Only the local throughput graph is on by default. Public IP checks, latency probes and the speed test are opt-in; those requests share your IP with Cloudflare by default. These are observations, not leak tests or proof that the VPN changed your public IP on a real Windows connection. No speed claim.

Defender on-demand scans on November 13, 2026 found no detection in the published v1.0.29 or v1.0.30 installers, both hash-verified. Engine 1.1.26100.4, signatures 1.463.277.0. Real-time protection was off on the hosted runner; a different cloud-delivered or real-time verdict on a live PC is still possible.

How to verify the installer

In PowerShell, run this command from the folder containing your download. Compare the result with the full published SHA-256 above. A matching hash confirms the file matches the published build; it does not prove that the software is safe.

Get-FileHash .\waX-VPN-Setup-v1.0.30-x64.exe -Algorithm SHA256

If Defender blocks or quarantines the installer, do not disable protection to install it. Check the detection name and report it on GitHub.

Can I download waX VPN yet?
Yes - v1.0.30 for Windows 10+ x64 is the current stable release. It is an unsigned build that requires administrator rights, so Windows publisher/SmartScreen warnings are expected. Earlier release checks passed, including a GUI-driven Connect handshake, through-tunnel ping, DNS apply/restore, split-tunnel exclusions, adapter-loss recovery, close-to-tray and graceful quit, and a fresh-runner install, GUI launch and uninstall (a CI Windows runner, not a consumer-PC/SmartScreen test). There is no kill switch - if the tunnel drops, traffic can use the normal connection - and no IPv6 leak-protection claim. The UAC restart path, tray menu and live WARP are still unverified, The Network page adds public IP observations, local throughput, HTTPS latency and a manual 10 MB speed test. Only local throughput is on by default; the external checks are opt-in and share your IP with Cloudflare by default. They are not leak tests, and the real Windows IP-change path remains unproven. Verify the SHA-256 in the Download section before running.
Is it a real VPN or a proxy?
waX is built to be a real system VPN: its tunnel code integrates the official WireGuard for Windows kernel driver, so all apps would route through the tunnel - not just one browser. A live handshake and clean disconnect against a WireGuard demo server have passed in CI, along with a GUI-driven connect and a through-tunnel ping; general real-machine traffic and crash safety are still pending.
What does WARP built in mean?
waX includes a Rust client written to the Cloudflare WARP API (the same protocol wgcf uses), so you could create and use WARP profiles without a separate tool. It is opt-in: no registration happens until you choose it in the app. Live interop with Cloudflare is untested, and WARP use is subject to Cloudflare's own terms.
Which platforms?
Windows 10+ x64 only. The current release was tested on hosted Windows Server 2025, not a clean Windows 10/11 image. Software (GDI) rendering is the default; GPU rendering is opt-in with --accelerated-graphics. No user-PC startup-crash fix is proven.
Is the source public?
Yes. Development happens in the open at github.com/vio137/wax-vpn.
